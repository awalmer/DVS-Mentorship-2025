# Datawrapper API

Here’s an example of using Datawrapper’s [script embed API](https://blog.datawrapper.de/web-component-embedding/) to embed a Datawrapper chart in Observable Framework.

## Script embed

The chart below is from a data visualization project I created about [Michelin Star Restaurants](https://aurawalmer.com/michelin).


<div class="card" style="max-width: 908px;">
    <script data-dark="true" defer src="https://datawrapper.dwcdn.net/KINMw/embed.js" data-target="#datawrapper-vis-KINMw"></script>
    <noscript>
        <img src="https://datawrapper.dwcdn.net/KINMw/full.png" alt="Michelin Star Restaurants 2023 (Copy) (Symbol map)"/>
    </noscript>
</div>
